Science Agent HTTP API for Tapis account identity, user-owned conversations, PostgreSQL attachments and selected S3 credential profiles. Authentication uses the X-Tapis-Token cookie, not a Bearer header. Browser clients must include credentials and use an allowed Origin. Agent execution uses WebSocket, described separately in x-websockets; it is not an HTTP operation. Storage operations use the authenticated user's selected S3 profile and are restricted to the science-agent/ prefix. Success payloads without a declared schema remain untyped; do not infer additional fields from an empty response schema.
